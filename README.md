# card_tester — программа проверки из «колоды карт»

Визуальный редактор программ проверки приборов. Карты действий из колоды
раскладываются слева направо, справа вводятся входные данные; выделенные
соседние карты можно обернуть в цикл FOR. Исполнение — через
[lib_visa](https://github.com/VoicelessUser/lib_visa) (VISA/SCPI).

## Запуск

```
python -m card_tester.main
```

Зависимости: `PySide6` (или `PyQt6`/`PyQt5`), `lib_visa` (`pip install -e external/lib_visa`).

## Как пользоваться

1. **Колода (снизу)** — карту можно **перетащить** в нужное место программы
   (летит «призрак» карты, место вставки подсвечивается, карты разъезжаются)
   или кликнуть — тогда карта добавится в конец:
   - **БП** — синие `Set V` / `Set I` (установка), зелёные `Meas V` / `Meas I` (измерения),
     фиолетовые `ON` / `OFF`;
   - **Мультиметр** — оранжевые `Meas V DC/V AC/I DC/I AC/R`;
   - **Система** — серая `Delay` (задержка, с).
2. **Параметры (справа)** — входные данные выбранной карты: канал, напряжение,
   ток и т.д. Значением может быть число, константа или переменная цикла.
3. **Константы и подключение (слева)** — общие константы (`имя = значение`,
   «+» добавляет; имя пишется в полях карт, напр. `Vcc`) и порты приборов.
4. **Перетаскивание** — карту можно тащить мышью (она «отрывается» и летит
   за курсором, как окно в Windows). Место вставки подсвечивается линией,
   остальные карты плавно разъезжаются. Можно перетащить карту внутрь
   цикла или обратно на ленту. **Обратно в колоду** — тащить карту (или
   шапку цикла) вниз, на док «Колода»: он подсветится красным, и при
   отпускании карта удалится из программы (пара ON/OFF удаляется вместе,
   сброс цикла — разбирает его, карты остаются).
5. **Цикл FOR** — выделите соседние карты (клик, Ctrl+клик, Shift+клик) и нажмите
   `⟳ Цикл`:
   - «Повторить N раз» (например 3);
   - «Диапазон»: переменная `i` от 1 до 5 с шагом — в полях карт пишите `i`
     (например `Set V = i` даст напряжение 1…5 В).

   Цикл выглядит как **жёлтая градиентная зона под картами**: клик по ней
   выделяет цикл (параметры справа), двойной клик — настройка,
   «Разобрать цикл» — убрать, оставив карты.
6. **График реального времени** — если в программе есть цикл-«Диапазон»
   (свипирование) и внутри него хотя бы одна `Meas`-карта, при запуске
   автоматически открывается график: **X — свипируемая переменная, Y — все
   измерения**, каждая Meas-карта — своя кривая. Точки появляются по мере
   выполнения. Открыть/скрыть — кнопка `📈 График`.
7. **Запуск** — `▶ Пуск`. Каждый шаг пишется в лог; измерения — `→ 3.298 В`.
   `⏹ Стоп` прерывает выполнение. По завершении все каналы БП выключаются.
8. **Сохранение** — 💾/📂: программа + настройки портов + константы в JSON.

## Подключение приборов

Настройка под текущий стенд: **БП Rigol DP832A** (`USB0::0x1AB1::0x0E11::DP8B262201226::INSTR`)
и **мультиметр AKIP-2101** (`USB0::0xF4EC::0xEE38::SDM35GBD6R2181::INSTR`) —
прописаны по умолчанию (`DEFAULT_PS`/`DEFAULT_MM` в `card_tester/main_window.py`).
Порт `test_float` в поле порта — **виртуальный режим без железа** (все команды
работают, измерения возвращают случайные числа). Кнопка «Проверить (*IDN?)»
проверяет связь.
