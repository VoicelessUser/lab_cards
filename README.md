# card_tester — программа проверки из «колоды карт»

Визуальный редактор программ проверки приборов. Карты действий из колоды
раскладываются слева направо, справа вводятся входные данные; выделенные
соседние карты можно обернуть в цикл FOR. Исполнение — через
[lib_visa](https://github.com/VoicelessUser/lib_visa) (VISA/SCPI).

## Запуск

```
python -m card_tester.main
```

Зависимости: `PySide6` (или `PyQt6`/`PyQt5`), `lib_visa` (`pip install -e external/lib_visa`).

## Как пользоваться

1. **Колода (снизу)** — карту можно **перетащить** в нужное место программы
   (летит «призрак» карты, место вставки подсвечивается, карты разъезжаются)
   или кликнуть — тогда карта добавится в конец:
   - **БП** — синие `Set V` / `Set I` (установка), зелёные `Meas V` / `Meas I` (измерения),
     фиолетовые `ON` / `OFF`;
   - **Мультиметр** — оранжевые `Meas V DC/V AC/I DC/I AC/R`;
   - **Система** — серая `Delay` (задержка, с), жёлтая `Свип` (свип-карта,
     см. п. 5b).
2. **Параметры (справа)** — входные данные выбранной карты: канал, напряжение,
   ток и т.д. Значением может быть число или константа (у Set-карты внутри
   свипа значение подставляет сам цикл).
   Прибор карты жёстко определяется стопкой, из которой она взята
   (`Meas` из «Мультиметра» — всегда мультиметр, из «БП» — только БП) —
   переключать его нельзя.
3. **Константы и подключение (слева)** — общие константы (`имя = значение`,
   «+» добавляет; имя пишется в полях карт, напр. `Vcc`) и порты приборов.
4. **Перетаскивание** — карту можно тащить мышью (она «отрывается» и летит
   за курсором, как окно в Windows). Место вставки подсвечивается линией,
   остальные карты плавно разъезжаются. Можно перетащить карту внутрь
   цикла или обратно на ленту. **Обратно в колоду** — тащить карту (или
   шапку цикла) вниз, на док «Колода»: карта в руке **краснеет**, и при
   отпускании она удалится из программы (пара ON/OFF удаляется вместе,
   сброс цикла — разбирает его, карты остаются).
5. **Цикл FOR** — выделите соседние карты (клик, Ctrl+клик, Shift+клик) и нажмите
   `⟳ Цикл`:
   - «Повторить N раз» (например 3);
   - «Свипирование»: цикл ведёт Set-карту **своего уровня** (От / До / Шаг),
     подставляя значения в её поле на каждой точке.

   Циклы можно **вкладывать друг в друга** (перетащить цикл в цикл или
   обернуть выделенные карты внутри цикла) — так получаются уровни
   свипирования. **Set-карты раздаются свипам автоматически**: каждый свип
   ведёт свою Set-карту (свипируемый параметр) — вложенный свип забирает свою
   карту первым, внешний берёт первую свободную из своего поддерева. Поэтому
   даже если все Set-карты лежат в самом внутреннем цикле, каждый из трёх
   вложенных циклов получит по своей переменной (карту для свипа можно
   выбрать и вручную в настройках цикла). Переменная, лежащая внутри
   вложенного свипа, применяется самим внешним свипом и вложенными
   не перезаписывается. Вложить цикл в самого себя нельзя.
   «Разобрать цикл» — убрать его, оставив карты (работает на любом уровне).

   Цикл выглядит как **жёлтая градиентная зона под картами**: клик по ней
   выделяет цикл (параметры справа), двойной клик — настройка.

5b. **Свип-карта** — отдельная жёлтая карта из стопки «Система» с тремя
   отсеками, растущими вместе с картами:
   - **X (слева)** — свипируемая величина: ровно одна `Set`-карта (ось X);
   - **середина** — любые карты, выполняются на каждой точке свипа;
   - **Y (справа)** — `Meas`-карты (ось Y): каждая даёт свою линию на графике.

   От / До / Шаг — в настройках свип-карты (клик по жёлтой зоне).
   Отсеки принимают карты по своим правилам: не-Set в X и не-Meas в Y
   положить нельзя, свип-карта в отсеки не вкладывается. «Разобрать свип»
   возвращает карты отсеков на ленту; сброс свип-карты в колоду тоже
   разбирает её. Свип-карты сочетаются с циклами-свипами: каждая работающая
   свип-карта и цикл-свип получают свой график.
6. **Графики свипов** — в окне отчёта при запуске: **свой график на каждый
   уровень свипирования** (вкладки «Свип 1», «Свип 2», …). X — переменная
   этого свипа, Y — измерения; Meas-карта попадает на график ближайшего
   объемлющего свипа, каждая Meas-карта — своя кривая. Точки появляются по
   мере выполнения. Число свипов определяют **Set-карты** (свипируемые
   параметры): свип без свободной Set-карты — не свип, Meas-карты на число
   уровней не влияют (они дают только кривые). **Свипов в программе нет —
   графиков нет** (остаётся таблица измерений). Кнопка
   «💾 Сохранить результаты» пишет CSV с измерениями и PNG каждого графика
   в папку `output/`.
7. **Запуск** — `▶ Пуск`: открывается окно отчёта (таблица измерений с
   временем, графики свипов, красное поле для ошибок). По завершении все
   каналы БП выключаются; закрытие окна приложения прерывает выполнение.
8. **Сохранение** — 💾/📂: программа (с вложенными циклами и привязкой
   свипов к Set-картам) + настройки портов + константы в JSON.

## Подключение приборов

Настройка под текущий стенд: **БП Rigol DP832A** (`USB0::0x1AB1::0x0E11::DP8B262201226::INSTR`)
и **мультиметр AKIP-2101** (`USB0::0xF4EC::0xEE38::SDM35GBD6R2181::INSTR`) —
прописаны по умолчанию (`DEFAULT_PS`/`DEFAULT_MM` в `card_tester/main_window.py`).
Порт `test_float` в поле порта — **виртуальный режим без железа** (все команды
работают, измерения возвращают случайные числа). Кнопка «Проверить (*IDN?)»
проверяет связь.
